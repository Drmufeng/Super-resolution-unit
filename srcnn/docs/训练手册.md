# 训练手册（srcnn 线）

## 入口分类

- 从零流程：`python run_full_from_scratch.py --only all`
- 单阶段运行：`run_pretrain_x2.py`、`run_finetune_x2.py`、`run_pretrain_x4.py`、`run_finetune_x4.py`

## 重要风险提示

- `run_full_from_scratch.py` 会清理历史权重与日志。
- 续训请不要用从零流程，改用单阶段脚本并设置 `resume_checkpoint`。

## 训练阶段

- x2 预训练：`configs/pretrain_x2_srresnet.json`
- x2 微调：`configs/finetune_x2_srgan.json`
- x4 预训练：`configs/pretrain_x4_srresnet.json`
- x4 微调：`configs/finetune_x4_srgan.json`

## 固定策略

- 预训练 `epochs=100`
- 微调 `epochs=60`
- `save_every=20`
- `*_best.pth` 覆盖更新

## 监控与早停

- 训练中自动调用 `eval.py` 做监控
- 每阶段监控频率由 `monitor.every` 控制
- 目标与早停由 `monitor.target_psnr/patience/min_delta` 控制
