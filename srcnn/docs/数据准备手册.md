# 数据准备手册

## 数据目录

- 训练集：`data/df2k/DIV2K_train_HR`
- 验证集：`data/df2k/DIV2K_valid_HR`
- 索引文件：`data/train_images.json`

## 压缩包来源

- `data/df2k/DIV2K_train_HR.zip`
- `data/df2k/DIV2K_valid_HR.zip`

## 索引生成

执行：

```bash
python prepare_data_index.py
```

脚本会扫描 `DIV2K_train_HR` 和 `DIV2K_valid_HR`，生成 `data/train_images.json`。
