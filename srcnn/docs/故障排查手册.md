# 故障排查手册

## 常见问题

- `No such file or directory: train_images.json`
  - 先运行 `python prepare_data_index.py`
- CUDA 不可用
  - 检查解释器是否为 `<项目根目录>/.venv_shared/Scripts/python.exe`
  - 检查 `torch` 是否为 CUDA 版本（如 `+cu128`）
- 评测失败
  - 检查 `configs/eval_*.json` 的 `checkpoint/lr_folder/hr_folder`
- 从头训练误清权重
  - `run_full_from_scratch.py` 与根目录 `one_click_retrain.py` 默认清权重
  - 续训必须使用单阶段脚本 + `resume_checkpoint`

## 快速自检

```bash
python -c "import torch; print(torch.cuda.is_available(), torch.__version__)"
```
