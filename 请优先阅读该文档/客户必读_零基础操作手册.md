# 客户必读：零基础操作手册
本手册用于交付客户快速上手。默认你不懂代码，也可以按步骤完成测试、训练和续训。

---

## 1. 先看最重要的风险

- 根目录的 `one_click_retrain.py` / `one_click_retrain.bat` 默认会清理已有 `.pth` 再从头训练。
- 如果你要保留已有模型继续训练，请用单阶段脚本并设置 `resume_checkpoint`。

---

## 2. 项目根目录每个文件夹做什么

- `sr30_workspace/`：EDSR 训练线（独立）
- `srcnn/`：SRResNet+SRGAN 训练线（独立）
- `.venv_shared/`：统一解释器环境
- `reports/`：一键测试报告输出
- `sr30模型备份/`：sr30 权重备份
- `srcnn模型备份/`：srcnn 权重备份
- `请优先阅读该文档/`：客户文档目录

根目录主要脚本：

- `one_click_retrain.py`：一键训练（默认清权重）
- `one_click_test_report.py`：一键测试并导出报告
- `setup_official_testsets.py`：安装官方测试集

---

## 3. 两条算法线区别

## `sr30_workspace`

- 算法：EDSR（PSNR-first）
- 核心脚本：`train_psnr_edsr.py`
- 配置：`configs/*_edsr.json`

## `srcnn`

- 算法：SRResNet 预训练 + SRGAN 微调
- 核心脚本：`train_srcnn.py`
- 配置：`configs/*_srresnet.json`、`*_srgan.json`

**注意**：两条线的 checkpoint 不能互相加载。

---

## 4. 每条线内部目录用途

共同结构含义：

- `configs/`：训练与评测参数
- `data/`：训练数据与 `train_images.json`
- `test/`：Set14/B100/Urban100 测试集
- `checkpoints/`：模型输出
- `checkpoints_backup/`：模型镜像备份
- `runs/`：训练日志与监控日志
- `outputs/`：评测输出图像
- `docs/`：该算法线的说明文档

## 6. 客户最推荐操作顺序

1. 先跑测试报告（安全，不清模型）：

```bash
python one_click_test_report.py --mode all --with-docx
```

2. 查看 `reports/` 下 `test_report_latest.*`。
3. 只有在确认需要重训时，才跑一键训练。

---

## 7. 三种训练方式

## A. 从零重训（会清模型）

```bash
python one_click_retrain.py --pipeline all --only all
```

## B. 只跑某一条线

```bash
python one_click_retrain.py --pipeline sr30 --only all
python one_click_retrain.py --pipeline srcnn --only all
```

## C. 续训（保留模型，推荐）

1. 在目标配置设置 `train.resume_checkpoint`
2. 增大 `train.epochs`
3. 运行单阶段脚本，例如：

```bash
python sr30_workspace/run_finetune_x4.py
python srcnn/run_finetune_x2.py
```
