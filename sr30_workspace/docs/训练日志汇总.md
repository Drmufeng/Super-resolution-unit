# 训练日志汇总说明

## 日志文件

- `runs/srresnet_x2/train_metrics.csv`
- `runs/srresnet_x2/val_metrics.csv`
- `runs/srresnet_x2/checkpoint_params.csv`
- `runs/x2/*`、`runs/srresnet_x4/*`、`runs/x4/*` 同理

## 关键字段

- `train_metrics.csv`: epoch、loss、lr、seconds
- `val_metrics.csv`: epoch、avg_psnr、avg_ssim
- `checkpoint_params.csv`: checkpoint 大小、参数统计、监控指标
