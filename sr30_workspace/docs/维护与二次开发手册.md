# 维护与二次开发手册

## 推荐改动入口

- 新实验配置：`configs/*.json`
- 新调度策略：`schedulers.py`
- 新训练逻辑：`train_psnr_edsr.py`

## 变更建议

- 优先通过配置改参数，少改主训练逻辑
- 变更后先跑 `--only x2` 小规模验证
- 保持日志字段兼容，便于历史对比

## 从零流程和续训区别

- `run_full_from_scratch.py`：会清理现有 checkpoint 与日志
- 单阶段脚本（如 `run_finetune_x4.py`）：可用于续训

## 单阶段续训（达到平台期前继续训练）

有两种续法：

- `init_checkpoint`：只加载权重，优化器重新开始
- `resume_checkpoint`：完整接着上次状态（推荐）

实操建议（最稳）：

1. 把配置里的 `train.epochs` 提高（例如 60 -> 100）
2. 设置 `train.resume_checkpoint` 为该阶段最新 checkpoint（或 best）
3. 保持 `save_every=20`
4. 继续运行该单阶段脚本

示例（sr30 x4 微调续训）：

- 配置：`configs/finetune_x4_edsr.json`
- 运行：`python run_finetune_x4.py`
